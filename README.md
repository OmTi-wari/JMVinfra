# Stellar Build

Build a Minimal, Premium Website for JAI MAA VINDHYAVASINI ENGINEERING INFRA

Create a modern, minimal and visually appealing corporate website for JAI MAA VINDHYAVASINI ENGINEERING INFRA, an engineering, construction and infrastructure company.

Overall Design Direction

The website should communicate:

- Engineering precision
- Construction strength
- Reliability
- Professionalism
- Modern infrastructure
- Trust

The design must be minimal, clean and premium, but NOT overly stylized or futuristic.

Avoid the typical generic construction-company website look.

Use a carefully balanced visual system with soft but eye-catching colours. The website should feel professional and trustworthy while still having enough visual personality to stand out.

Colour Direction

Use a soft infrastructure-inspired palette:

- Deep navy / charcoal for primary text and headers
- Warm off-white / ivory for backgrounds
- Muted steel blue as a supporting colour
- Soft terracotta / burnt orange as an accent
- Very subtle concrete-grey sections

The accent colour should be used selectively for buttons, highlights, icons and important visual elements.

Do NOT use:

- Neon colours
- Extremely saturated colours
- Excessive gradients
- Pure black backgrounds everywhere
- Overly flashy animations

The overall appearance should feel like modern architecture + engineering documentation + premium corporate design.

Typography

Use a modern professional sans-serif font.

Recommended:

Manrope, Inter, or Plus Jakarta Sans

Use:

- Strong bold typography for headings
- Regular weight for body text
- Generous line height
- Large but controlled hero typography

Avoid decorative fonts.

The typography should feel like a premium architecture/engineering firm.

---

Layout & Spacing

Prioritize whitespace.

Use:

- Wide content containers
- Generous section spacing
- Clean grid systems
- Consistent margins
- Rounded corners only where appropriate

Do NOT make every component rounded.

Avoid excessive cards.

The website should breathe.

---

Animations

Use subtle animations only.

Examples:

- Fade-up on scroll
- Slight image zoom on project hover
- Smooth navigation scrolling
- Subtle button hover
- Gentle navbar transition

No:

- Excessive parallax
- Flashy page transitions
- Spinning elements
- Large animated text
- Constant movement

The website should feel calm and confident.

---

Image Direction

Images are extremely important.

Use high-quality photography related to:

- Infrastructure
- Modern buildings
- Bridges
- Construction
- Structural engineering
- Architectural details
- Industrial construction
- Engineering drawings

Prefer realistic professional photography.

Avoid obvious stock images whenever possible.

Structure the project gallery so the company's actual project photographs can replace placeholder images easily.

---

Responsive Design

The website must be fully responsive.

Desktop:

- Wide editorial layouts
- Large project imagery
- Two-column sections

Tablet:

- Simplified grids
- Reduced spacing

Mobile:

- Single-column layout
- Large readable typography
- Full-width CTA buttons where appropriate
- Hamburger navigation
- Project cards stacked vertically
- No horizontal scrolling

The mobile version should feel intentionally designed, not like a compressed desktop website.

---

Technical Requirements

Build the website with clean, reusable components.

Create reusable components for:

- Navbar
- Hero
- Section heading
- Service card
- Project card
- Statistics
- CTA
- Contact form
- Footer

Keep content and data easy to modify.

Create a central data structure for:

- Services
- Projects
- Company statistics
- Contact information

This will allow the company information to be updated later without restructuring the entire website.

Use semantic HTML and proper accessibility practices.

Optimize images and loading performance.

Add SEO-friendly:

- Page title
- Meta description
- Open Graph metadata
- Proper heading hierarchy
- Image alt text

---

Important Content Rule

Do NOT invent company facts.

Do not claim:

- Number of projects
- Years of experience
- Number of employees
- Revenue
- Major clients
- Government contracts
- Certifications
- Awards
- Locations
- Project values

unless those details are explicitly provided.

Use editable placeholders where information is missing.

---

Final Design Goal

The final website should feel like:

A modern engineering and infrastructure company that is established, reliable and technically capable.

Think:

Architecture studio × Engineering firm × Premium construction company

—not—

generic contractor website × flashy startup × overly futuristic design.

The most important qualities should be:

Minimal → Professional → Visual → Trustworthy → Modern → Easy to Navigate

The website should look impressive within the first 5 seconds without feeling over-designed.
